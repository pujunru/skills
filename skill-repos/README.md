# skill-repos/

Git submodules live here. Each submodule is a standalone skill repository
(see [`../skill-repo-template`](../skill-repo-template)) that holds one
themed collection of skills.

This directory is intentionally empty until you add your first submodule —
see the root [README](../README.md#adding-a-new-skill-repo-submodule) for
the `git submodule add` workflow.
